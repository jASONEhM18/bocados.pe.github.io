# Bocados.pe 🌐

Plataforma web en producción desplegada y mantenida de forma continua.

👉 **Accede a la web en vivo:** https://bocados-pe.vercel.app

---

### 🚀 Arquitectura y despliegue

Este repositorio funciona como punto de entrada público y documentación del proyecto. El entorno de producción sigue un flujo de integración y despliegue continuo (**CI/CD**):

- **Hosting y CDN:** Desplegado en **Vercel** con certificados SSL/TLS automáticos y distribución global.
- **Flujo de actualización:** Cada cambio validado en la rama principal dispara una compilación y publicación automática en producción sin tiempo de inactividad.
- **Seguridad del código:** El repositorio principal con el código fuente en **TypeScript** se mantiene en privado por tratarse de un proyecto activo en evolución semanal.
